# Decision V2 — No mid-width overflow; panel never leaves a sliver
Judged by one independent judge agent applying the usability, visual-craft and engineering lenses (scores are its reading). External judges (MUSE Wonder, Gemini Argon) were skipped: no OPENROUTER_API_KEY. Implementation order on one branch: V5 → V1 → V2 → V3 → V4.

| Proposal | Usability | Visual | Engineering | Total |
|---|---|---|---|---|
| A Shrinkable grouped filters + full-width panel <840 | 4 | 4 | 5 | **13** |
| B Filter toolbar unit + clamp panel | 4 | 3 | 3 | 10 |
| C Filters popover + chips + sheet | 3 | 4 | 1 | 8 |

## Decision: A, with a graft from B
**Tokens.** `--filter-width:190px; --filter-min:120px; --panel-width:680px; --panel-reveal-min:160px`.

**Filters.**
- Each filter label: `nav label{flex:0 1 var(--filter-width);min-width:var(--filter-min);white-space:nowrap}`. Keep `nowrap` scoped to the nav; a global rule would break form labels on phones.
- Grouping: one `nav > button + label{margin-left:auto}` replaces the per-label margin. The ≤760px media query must reset `nav > button + label{margin-left:0}` explicitly, because this selector out-specifies the existing reset.
- Selects: `nav select{min-width:0;text-overflow:ellipsis}`.

**Panel.** `.side-panel{width:min(var(--panel-width),100%)}`, plus `@media (max-width:839px){.side-panel{width:100%}}`. 839 = 680 + 160 − 1; comment that link in the CSS.

**Graft from B.** Put a `title` with the selected vein's full name ("All veins" when none) on the Vein select.

**Do not.** No filter wrapper DOM, no container-query row, no Filters popover.

## Defense
- **vs B:** its extra 70px row eats V1's chrome budget at 700px heights.
- **vs C:** it hides filters (a product change), overlaps #113, breaks phone test locators, and is effort L.
- **Norms satisfied:** L6, D4, C4, L4.
- **Cost:** about 14 CSS lines and one attribute.
- **Interaction:** between 761 and 839px the full-width panel hides the page chrome. V3 must not rely on page controls there while a panel is open.

## Acceptance criteria
1. With seed data plus a 120-character vein title, the page never scrolls sideways (`scrollWidth <= innerWidth`) at:
   - every width from 320 to 1920 in 16px steps;
   - 761, 767, 768, 839, 840 and 867.
2. At 768×1024 with a panel open, Close's right edge is ≤ 768.
3. Filter select widths stay within their share; a long vein title truncates. The three filters are right-grouped with gaps ≤ 10px.
4. The board visible beside the panel is either ≥ 160px or 0.

## Test plan
- Create a long-title vein via CLI.
- Sweep widths, asserting `scrollWidth`.
- At 768: open a card and check Close's bounding box.
- Select the long vein: select width ≤ 191 and `title` equals the full name.
- At 839 and 840: `innerWidth − panel width` is 0 or ≥ 160.
