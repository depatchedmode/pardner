# F-104-01: task panel and Activity copy polish

**Unit:** qf-4 · **Findings:** F-104-01, F-082-01, F-088-03 (partly), F-138-04, F-080-02 (partly), F-075-02, F-075-03 (partly) · **Severity:** medium

## Problems and changes (all in `ui-prototype/src/Pardner.jsx`)
1. **Raw type tooltip (F-104-01).** Every Activity and History row had `title={event.type}`, so hovering over a row showed strings such as "task.update". The attribute is removed.
2. **Two date formats in one panel (F-082-01, F-138-04, F-088-03).** Comment headers used `toLocaleString()`, which shows seconds ("11/9/2026, 11:36:42 AM"). History used the medium date with a short time. Comments now use the History format, and the `<time>` element now has a `dateTime` attribute.
3. **Identical Unlink buttons (F-080-02).** Each Unlink button now has an accessible name that includes its issue, for example "Unlink acme/lantern-checkout#481".
4. **Newer-save notice credited one Actor for every field (F-075-02, F-075-03).** Each newer field is now credited to the Actor whose History event last changed it. Fields with the same author are grouped, field lists are joined with "and", and groups are separated with a semicolon, for example "Carol Moreno · human saved a newer status; Builder · agent saved newer tags since you started editing." A field with no matching event is credited to "Someone", as before.

## Not changed
- **F-088-03:** Activity quotes still show raw Markdown. The triage scoped this out.
- **F-080-02:** focus still falls to the page body after Unlink. Moving focus to a sensible next target needs a design choice: the next link, the input, or the section heading.
- **F-075-03:** the notice still uses lower-case field keys ("status", "tags") rather than the form labels. Only the list grammar was in scope.

## Tests (`test/pardner-ui.test.js`)
- "describes Activity and task History as plain sentences": no Activity row has a `title` attribute; the Unlink button is named "Unlink acme/lantern-checkout#418"; a comment time matches the History format.
- New test, "credits each newer field to the Actor who saved it": while a draft is open, Carol changes the status and Builder changes the tags. The notice reads "Carol Moreno… saved a newer status; Builder… saved newer tags since".
